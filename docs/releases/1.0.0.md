The first release of **Open Cowork for Android**, a native client for your self-hosted [Open Cowork](https://github.com/Cametendo/open-cowork) server.

### Install

1. Download `open-cowork-android_1-0-0.apk` below on your phone.
2. Open it. Android asks once to allow installing apps from your browser or file manager; allow it.
3. Open the app and sign in with your email and password, plus your server as **IP + port** (e.g. `192.168.1.20` and `3001`) or a **domain** (e.g. `cowork.example.com`).

Needs Android 8.0 or newer and an Open Cowork server your phone can reach (same Wi-Fi, VPN or a public domain).

### What's in it

- **Chats:** streaming replies with Markdown, code and reasoning, model picker, image attachments, edit, regenerate, stop and per-chat settings
- **Cowork:** tasks in a scratch folder or a repository, Ask-first or Auto mode, live steps with diffs and command output, Allow / Deny, a file browser and a Git panel (commit, pull, push, pull requests)
- **Repositories, settings and the full admin panel**
- **Keeps working when you close the app:** replies keep generating, and Cowork asks for approvals through notifications with Allow / Deny buttons
- **Light blue and dark blue themes** (follows your phone), customizable colors, and separate wallpapers for chats and Cowork tasks
