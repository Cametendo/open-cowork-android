**Web search** is here, matching the update to the Open Cowork server.

- **Chat:** a *Web search* switch next to the message box searches first, then answers with numbered sources. Citations like `[1]` are tappable, and source chips appear under the reply. Your choice is remembered.
- **Cowork:** the agent can search the web and read pages. These steps show up in the task like any other and never ask for approval.
- **Admin › Web search:** turn it on, pick DuckDuckGo, SearXNG, Brave or Tavily, enter a SearXNG URL or API key, set results per search, allow private addresses, and test the search.

Web search is off by default and needs a server with web search (Open Cowork 0.2 or newer). Without it the app looks and works as before.

### Update

Install the new APK over the old one. If Android says the app conflicts with an existing one, uninstall 1.0.0 first (the 1.0.0 build was signed with a temporary key).
